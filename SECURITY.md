# Security policy

## Reporting a vulnerability

Do not open a public issue for security problems.

Report them through GitHub's
[private vulnerability reporting](https://github.com/lukacs-m/SudokuWorld/security/advisories/new)
so the details stay confidential until a fix ships. You will get an
acknowledgement within a few days.

## Supported versions

Only the latest App Store release and the `develop` branch receive security
fixes.
